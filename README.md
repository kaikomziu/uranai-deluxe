# 占いDELUXE 🔮

毎日変わる運勢占いと、運試しゲームがたくさん詰まった占いサイトです。

## 遊べる内容

### 🔮 今日の占い(日付が変わると結果も変わります)
- 🎋 おみくじ(8段階の運勢 × 5項目 + ラッキーカラー/アイテム/ナンバー)
- ⭐ 星座占い(12星座、日替わりランキング付き)
- 🩸 血液型占い(A/B/O/AB型、今日の相性つき)
- 🐉 干支占い(生まれ年から十二支を判定)

### 🎲 運試しゲーム
- ✊ じゃんけん(連勝記録に挑戦)
- 🪙 コイン占い / 🎲 サイコロ占い
- 🎡 運勢ルーレット
- 🃏 ミニタロット占い(大アルカナ22枚)
- 🔢 ラッキーナンバー診断

### 🥚 隠し要素(イースターエッグ)
サイトのあちこちに、7つの隠し要素を仕込んでいます。見つけると「隠し要素コレクション」に記録されます。

## 技術構成
- Vanilla HTML / CSS / JavaScript(ビルド不要)
- 日替わり結果は日付文字列をシードにした擬似乱数(mulberry32)で生成しているため、同じ日なら誰が見ても同じ結果、日付が変わると自動的に新しい結果になります。
